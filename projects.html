Math Quiz Terminal of Doom

C++ Win32 API System Calls Low-Level
Quiz de matemática no terminal construído em C++ com a Win32 API. O diferencial: se o usuário perder todas as vidas — calculadas com base na RAM real do sistema — o computador reinicia. Sem piedade.

Destaques:
  • Acesso direto à memória via Win32 API.
  • Engine de renderização customizada no terminal.
  • Integração com comandos de reboot no nível do sistema.
